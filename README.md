# IBD Classification from Gut Microbiome Data Using CNNs

This is part of a Bachelor's Thesis for the Data Science and Society programme at the University of Groningen. The thesis investigates to what extent does incorporating demographic and lifestyle host metadata alongside taxonomic abundance data from the AGP into a CNN architecture influence gut microbiome IBD classification, compared to using abundance data alone. The approach encodes taxonomic abundance profiles into 2D image representations to enable spatial feature extraction without requiring explicit feature pre-selection. The repository includes exploratory data analysis, data filtering and preprocessing, and a CNN modeling pipeline.

## 🗄️ Data

The original raw dataset is too large to host on GitHub. Download it from Google Drive and place it in the `data/raw/` folder:

📥 **[Download raw dataset](https://drive.google.com/drive/folders/1WsMSCZWK7fXvdhvERiMwvrwOUsrpVBsp?usp=share_link)**

All preprocessed files used by the CNN pipeline are derived from this raw data by running the notebooks in order (see below). The `data/preprocessed/` folder contains:

| File | Description |
|---|---|
| `preprocessed_binary.npz` | Taxa images — binary presence/absence encoding |
| `preprocessed_normalized.npz` | Taxa images — relative abundance (0–1) |
| `preprocessed_log.npz` | Taxa images — log-transformed abundance |
| `encoded_metadata.npz` | Encoded clinical metadata (20 features) |

## ▶️ How to Run

Run the notebooks and pipeline in order:

1. **`notebooks/EDA.ipynb`** — explore the raw data
2. **`notebooks/preprocessing.ipynb`** — generate all preprocessed files in `data/preprocessed/`
3. **`run_pipeline.py`** — run the full CNN training pipeline

### Step 3: Running the CNN Pipeline

- **image-only baseline** (Phases 1–3 for all three representations)
- **metadata-fusion model** (Phases 1–4, including feature importance)
- **summary tables and visualizations**

Results are saved incrementally to `results/` after each representation.

#### Running Locally

```bash
python run_pipeline.py
```

#### Running on Habrok Cluster

Submit the job to the cluster using:

```bash
sbatch job.sh
```

The `job.sh` script handles environment setup and resource allocation. Monitor job status:

```bash
squeue -u $USER
scontrol show job <JOB_ID>
```

Check output:

```bash
cat slurm-<JOB_ID>.out
```
